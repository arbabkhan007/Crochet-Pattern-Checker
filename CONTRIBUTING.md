# 🤝 Contributing

Thank you for contributing! Please read our guidelines.

## 🐛 Report Bugs
[Open an issue](https://github.com/arbabkhan007/Crochet-Pattern-Checker/issues/new?template=bug_report.md)

## 💡 Request Features
[Open a feature request](https://github.com/arbabkhan007/Crochet-Pattern-Checker/issues/new?template=feature_request.md)

## 🔧 Code Contributions
1. Fork the repo
2. Create a branch (`git checkout -b feature/amazing`)
3. Make changes and add tests
4. Run `pytest` (must pass all 146 tests)
5. Commit and push
6. Open a Pull Request
