# Novality Crochet Studio — pattern kits

Ten amigurumi patterns, each rebuilt as a complete digital-product kit: a designed PDF, an Etsy listing kit (10 images + SEO copy),
a chaptered narrated audio walkthrough and a 1080p tutorial video. **Every stitch count in every pattern was verified deterministically**
(`engine/verify.py`) before publishing — 412 rounds across 10 patterns, 0 errors.

All patterns are branded *Novality Crochet Studio* only.

## Pattern details

### Axel the Axolotl — NS 03

A soft pink axolotl with six fluffy gills, a round head and a shell-edged paddle tail. Head, neck, body and tail are worked as one continuous spiral - no neck seam to sew.

- Size: 11.5 cm / 4.5 in tall · Advanced beginner · US terms · 2.5 - 3 hours
- Rounds verified: **52**, 0 count errors
- Files: `out/axel/` — `Axel_the_Axolotl_Pattern.pdf`, `etsy/` (10 images + LISTING_COPY.md + listing.json), `audio/` (9 chapter MP3s), `Axel_the_Axolotl_Full_Walkthrough.mp3`, `Axel_the_Axolotl_Tutorial.mp4`, `chapters.txt`

### Coco the Capybara — NS 04

A low, round, bottom-heavy capybara with a blunt sewn-on muzzle, plump stuffed legs and a calm embroidered sleeping face. The legs are crocheted straight into the body as you go, so Coco stands on her feet, not her belly.

- Size: 10.3 cm / 4 in tall · Intermediate · US terms · 2.5 - 3 hours
- Rounds verified: **37**, 0 count errors
- Files: `out/coco/` — `Coco_the_Capybara_Pattern.pdf`, `etsy/` (10 images + LISTING_COPY.md + listing.json), `audio/` (8 chapter MP3s), `Coco_the_Capybara_Full_Walkthrough.mp3`, `Coco_the_Capybara_Tutorial.mp4`, `chapters.txt`

### Ember the Baby Dragon — NS 08

A chubby sitting baby dragon with a big round head, a pale belly patch, two scalloped wings and a ridge of nine spikes running from the crown to the tail tip. The head and body are worked separately and joined open-edge to open-edge, so the neck join is sturdy and invisible.

- Size: 11 cm / 4.3 in seated · Intermediate · US terms · 4 - 5 hours
- Rounds verified: **70**, 0 count errors
- Files: `out/ember/` — `Ember_the_Baby_Dragon_Pattern.pdf`, `etsy/` (10 images + LISTING_COPY.md + listing.json), `audio/` (10 chapter MP3s), `Ember_the_Baby_Dragon_Full_Walkthrough.mp3`, `Ember_the_Baby_Dragon_Tutorial.mp4`, `chapters.txt`

- Size: 16 cm / 6.25 in tall · Confident beginner · US terms · 1.5 - 2 hours

## Rebuilding

```
python -m venv .venv && .venv/bin/pip install pymupdf reportlab pillow imageio imageio-ffmpeg numpy
python engine/verify.py                 # all 10 patterns, exit 1 on any count problem
python engine/prep_images.py <slug>     # PNG photos -> JPEG for the PDF
python engine/build_pdf.py <slug>
python engine/build_etsy.py <slug>      # 10 listing images + LISTING_COPY.md (needs the PDF)
python engine/build_video.py <slug>     # needs out/<slug>/audio/<chapter>.mp3 (see engine/narration.py for the scripts)
python build_all.py [slugs]             # everything above in order
```

Pattern data lives in `patterns/<slug>.py`; the engine is fully data-driven, so a count fix is a one-line edit followed by `build_all.py`.
