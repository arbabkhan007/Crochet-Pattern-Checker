# Pattern confirmation proofs

`NS01_Hamish_the_Highland_Cow_CONFIRMATION_PROOF.pdf` is the first visual-system proof for approval before the remaining pattern PDFs are composed.

It uses the requested **Novality Crochet Studio** branding, prominent **NS 01** identification, the original ginger/oat-cream/dark-chocolate/rust colour story, bookmarks, repeated table headers, copyright notices and three distinct visual assets.

The cover animal is explicitly labelled **concept imagery** inside the PDF. It is not evidence of a physically completed sample and must be replaced with photographs of the tested finished object before retail release. The proof itself is marked “not for retail” and “do not distribute”.

## Rebuild

```bash
python -m venv /tmp/novality-pdf
/tmp/novality-pdf/bin/pip install -r requirements-release-pdf.txt
/tmp/novality-pdf/bin/python tools/build_ns01_confirmation_pdf.py
```

Do not build NS 02–NS 15 until this visual direction is approved or revised.
