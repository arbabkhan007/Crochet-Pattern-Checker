# Edition 2 — Corrected Patterns (NS01–NS17)

Standalone corrected drafts of all 17 Novality patterns, regenerated from the
Edition 1 review files with every confirmed critique correction applied.

- `NS01_edition2.md` … `NS17_edition2.md` — the corrected patterns.
- `verify.py` — table-driven arithmetic audit (run from anywhere; it finds the
  bundled `tools/pattern_release_audit.py` next to it, or the repo `tools/`).
- `check_tests.py` — 6-test regression suite (mutations, NS04 reference map,
  NS09 symmetry, NS13 star wrap, NS17 sash modules).
- `cases.json`, `prose-checks.json` — exact-text arithmetic/prose coverage.
- `stitch-ledger.json` — generated audit ledger (regenerated by `verify.py`).

Run:

    python verify.py
    python check_tests.py
