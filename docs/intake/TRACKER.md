# Novality Store pattern intake queue

Fifteen patterns will be pasted one by one. Each paste is stored verbatim as
`NN_<slug>.txt` in this folder (slot number = order of arrival). No validation,
correction or PDF compilation happens until all 15 slots are filled; then every
pattern goes through the standard pipeline in slot order:

1. independent stitch-count audit (`audit_nsXX.py`) + repo 5-axiom engine run
2. corrected engine-clean master `NSXX_corrected.md` + validation report
3. colour store-edition PDF (white cover, framed render, footer stamps, appendices)
4. monochrome ink-saver PDF (0 % colour fills, #333 outlines, greyscale hero)
