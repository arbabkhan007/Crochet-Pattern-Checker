## 1. Compliance first — read before publishing

Three rules govern this listing. All three are satisfied by the copy below; do not delete the disclosure lines.

1. **AI disclosure is mandatory and goes in the description.** Etsy's Creativity Standards (updated 10 Jun 2025): *"Sellers must disclose within their listing description if an item is created with the use of AI."* The cover photograph and the bobble macro in this PDF are AI-generated renders, so the disclosure line below must stay in the description [2](https://www.growtsy.com/etsy-ai-policy).
2. **Images must not misrepresent what the buyer receives.** The buyer receives a PDF, not a skirt. No finished NS 14 skirt has ever been crocheted or photographed by the studio (the pattern says so itself), so the renders are labelled *"illustrative render — not a photograph of a sample"* on the cover, and the description repeats it. Do not remove that label, and do not state finished measurements as measured facts [5](https://nightjar.so/blog/ai-product-photos-for-etsy-shop).
3. **The pattern's own licence terms.** Finished-item listings by buyers must credit "Pattern by Novality Crochet Studio · Design Code NS 14" and must not claim unverified safety, testing, size, yarn-quantity, fit or care results. Your own listing should model that behaviour.
