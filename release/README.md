# Novality Crochet Studio customer PDFs

This directory contains the A4 two-file customer system for Design Codes
**NS 01–NS 17**:

- a branded, full-colour crochet-pattern PDF with named original colours,
  selectable text, bookmarks, repeated table headers, copyright/licence text
  and printable `[ ]` progress boxes; and
- a matching black-on-white, raster-free **PRINTER SAVER** companion for
  economical home printing.

The NS 16–NS 17 customer archive
[`Novality_Crochet_Studio_NS16-NS17_PDF_AND_MARKDOWN_COLLECTION.zip`](Novality_Crochet_Studio_NS16-NS17_PDF_AND_MARKDOWN_COLLECTION.zip)
contains exactly six files in three folders: two colourful PDFs, two
black-and-white printer PDFs and the two authoritative Markdown masters.

The earlier complete NS 01–NS 15 archive
[`Novality_Crochet_Studio_NS01-NS15_COMPLETE_PDF_AND_MARKDOWN_COLLECTION.zip`](Novality_Crochet_Studio_NS01-NS15_COMPLETE_PDF_AND_MARKDOWN_COLLECTION.zip)
remains unchanged and contains 45 files: 15 colourful PDFs, 15 printer PDFs
and 15 Markdown masters. The smaller
[`Novality_Crochet_Studio_NS02-NS15_PDF_Collection.zip`](Novality_Crochet_Studio_NS02-NS15_PDF_Collection.zip)
contains only the 28 NS 02–NS 15 PDFs. Individual PDFs can also be downloaded
separately for use as the two buyer files in each Etsy listing.

## Visual and colour treatment

Every full-colour edition shows the original colourway visually and by name.
NS 02–NS 17 each contain exactly two raster visuals: one labelled illustrative
cover composition and one labelled maker map. NS 01 contains three labelled
illustrative visuals: cover, materials and assembly map. No visual is presented
as a photograph of a physically tested sample.

The NS 02–NS 08 cover compositions are illustrative crochet renderings. The
NS 09–NS 17 covers and all maker maps are original programmatically drawn
editorial graphics. The printer-saver editions contain no raster image objects
and use grayscale vectors on white page backgrounds.

No genuine sample/process photography was supplied. Generated or drawn visuals
must not be used as physical-test evidence. Replace them only with
rights-cleared photographs of the actual tested sample, and keep those
photographs clearly separate from diagrams or illustrative graphics.

## Validation performed

The release builder rejects a customer file unless it passes source-content
sentinels, page identity, metadata, A4 geometry, file-size, bookmark,
original-colour-name, progress-box and image-inventory checks. Its printer-saver
gate also rejects any raster object or non-grayscale vector colour.

## Rebuild and postflight

```bash
python -m venv /tmp/novality-pdf
/tmp/novality-pdf/bin/pip install -r requirements-release-pdf.txt

# Approved NS 01 pair
/tmp/novality-pdf/bin/python tools/build_ns01_etsy_pdf.py

# Established NS 02–NS 15 pairs and PDF-only convenience ZIP
/tmp/novality-pdf/bin/python tools/build_remaining_pattern_pdfs.py

# NS 16–NS 17 pairs; package exactly their six requested customer files
/tmp/novality-pdf/bin/python tools/build_remaining_pattern_pdfs.py \
  --codes 16-17 --skip-bundle
/tmp/novality-pdf/bin/python tools/package_ns16_ns17.py

# Render every NS 16–NS 17 page and create review galleries under build/
/tmp/novality-pdf/bin/python tools/render_collection_review.py --codes 16-17
```

Build another selected group with, for example,
`--codes 2,5,9-11 --skip-bundle`. A partial build never silently rewrites a
collection ZIP.

## Commercial release status

**PDF production is complete; commercial release remains on HOLD.** These files
passing desk, arithmetic, content and rendering checks does not prove that the
patterns have been crocheted successfully, that supplied quantities or sizes
have been measured, that titles/visuals/brands are cleared, or that a finished
item complies with product-safety law.

Before any Etsy listing goes live, close the physical sample, independent
tester, provenance/title/brand, rights-cleared photography, product-safety,
legal and current Etsy disclosure/listing gates in
[`../reports/commercial_readiness.md`](../reports/commercial_readiness.md). In
particular, review Etsy's current disclosure requirement for seller-prompted AI
creations and do not describe these illustrations as real product photography.
